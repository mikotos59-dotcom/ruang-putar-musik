# Ruang Putar Musik

Pemutar musik Android yang **ringan dan khusus musik**: cari, putar, dan simpan lagu dari YouTube
tanpa iklan dan tanpa akun. Dibuat oleh **@SuS_X_x**.

- Android 7.0 sampai Android terbaru
- Ukuran ± 3,5 MB

## Fitur
- Cari lagu (filter *Lagu* / *Semua video*) dengan halaman ◀ ▶
- Putar di latar belakang: notifikasi, layar kunci, tombol headset/Bluetooth
- Antrean (naik/turun/hapus), acak, ulang, timer tidur
- Favorit, Riwayat, **Sering kamu putar**
- Beranda dengan rak + filter durasi; rak dari penyanyi favorit
- Halaman penyanyi: lagu lain, ikuti penyanyi
- Unduh ke Offline → folder `Music/RuangPutar` (M4A/Opus)
- Cache lagu, batas kecepatan unduh (Rendah / Normal / Tanpa batas)
- Tema Gelap / Terang / Batik
- Bagikan link YouTube dari aplikasi lain → langsung diputar
- Pembaruan dari dalam aplikasi: **Pengaturan → Pembaruan**

## Unduh & pasang
1. Buka halaman **[Releases](../../releases/latest)** → unduh file `.apk` terbaru.
2. Buka file tersebut di HP → izinkan "Instal aplikasi tidak dikenal" bila diminta → **Instal**.
3. Versi berikutnya cukup lewat **Pengaturan → Pembaruan → Perbarui** di aplikasi.
